Unique Feature

Menu bar styling.

No other app lets you style the macOS menu bar itself. Apply solid colors, multi-stop gradients, dynamic time-based themes, or frosted glass effects.

  • Solid, gradient, dynamic, frosted glass modes
  • Adjustable opacity and blend modes
  • Built-in presets: Midnight, Sunset, Ocean, Forest
  • Click-through overlay, fullscreen aware
System

Deep system monitoring.

CPU, memory, disk, network, GPU utilization, temperature sensors, top processes, and Bluetooth device batteries. Everything iStat Menus offers, built natively.

  • Per-core CPU with sparkline graphs
  • 40+ temperature sensor readings via SMC
  • AirPods, Magic Mouse, keyboard battery levels
  • Top processes sorted by CPU or memory

Extensible

xbar script engine.

Run any shell script and display the output in your menu bar. Full compatibility with the xbar/SwiftBar plugin format. Thousands of community scripts work out of the box.

  • Bash, Zsh, Python, Ruby, Node - any language
  • Color, font, icon, href pipe parameters
  • Nested submenus and separator support
  • Security hardened: shell whitelist, path validation
