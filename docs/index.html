Install

Up and running
in 60 seconds.

Barista is distributed as a standalone .app. No installer, no account, no subscription.

Download the DMG

Click Download for macOS above to get Barista.dmg. Double-click the file to open the disk image.

Drag to Applications

You'll see Barista.app and an Applications shortcut. Drag the app onto the Applications folder. That's the whole install.

Open with Right-Click

On first launch, right-click Barista in Applications and choose Open, then click Open in the dialog. You only need to do this once.

macOS Gatekeeper notice

Barista is open source and ad-hoc signed. On first launch, macOS will show "Barista can't be opened because Apple cannot check it for malicious software." This is normal for apps distributed outside the App Store. Right-click and choose Open to bypass this. Alternatively, go to System Settings > Privacy & Security and click Open Anyway. You can inspect the full source code on GitHub.

Prefer the terminal?

Download, mount, copy, and open - all in one go:

curl -sL https://github.com/noamsmall18/barista/releases/download/v1.0.0/Barista.dmg -o /tmp/Barista.dmg hdiutil attach /tmp/Barista.dmg -nobrowse -quiet cp -R /Volumes/Barista/Barista.app /Applications/ hdiutil detach /Volumes/Barista -quiet xattr -cr /Applications/Barista.app open /Applications/Barista.app
