# Marketbar identity

Generated with the built-in imagegen tool: a minimal electric green M on black,
with a restrained glow. Marketbar uses this icon in macOS and the research desk.
Barista retains its separate legacy icon.

The generated original is `MarketbarIcon.png`, the macOS export is
`MarketbarIcon.icns`, and the web export is `Barista/Web/marketbar-logo.png`.
Exports use `sips` for standard resizing and the ICNS PNG container format;
the generated artwork is unchanged.
