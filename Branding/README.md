# Marketbar identity

Marketbar's identity is an emerald glass prism with a rising market trace,
set against a near-black rounded app tile. Barista retains its separate icon
and warm amber accent.

The original square artwork is `MarketbarIcon.png`, the macOS app export is
`MarketbarIcon.icns`, and the research desk and browser favicon use
`Barista/Web/marketbar-logo.png`. The macOS export is built from the original
at standard icon sizes with `iconutil`; the web export is a 256 px PNG.

The app and research desk use the same original artwork. Marketbar's native UI
uses an emerald primary accent derived from the prism; Barista's theme stays
unchanged.
